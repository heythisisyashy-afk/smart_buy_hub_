# SmartBuy Hub — rebuilt for Netlify

This is a responsive storefront starter with:
- Product catalogue, search, category filter, cart, and checkout.
- Login and account creation using Supabase Auth.
- Server-side Google Sheets product/order storage through Netlify Functions.
- Admin-only product creation form.
- Cash on Delivery and Razorpay checkout with server-side signature + captured-payment verification.
- Demo product fallback so the catalogue never stays on “Loading products…” forever.

## Important before launch
This is starter code, not a deployed or configured store. You must connect the services below, set your own administrator email, and test in sandbox/test mode before taking real orders. Do not share private credentials or upload a service-account JSON file to public GitHub.

See `SETUP.md` for step-by-step setup.
